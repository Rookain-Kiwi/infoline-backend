# InfoLine Backend API

API REST Java Spring Boot pour la plateforme InfoLine - Actualités des technologies sportives.

## Stack Technique

- Java 17
- Spring Boot 3.x
- PostgreSQL (AWS RDS)
- Docker
- Kubernetes (AWS EKS)

## Structure du Projet
```
src/
├── main/
│   ├── java/com/infoline/api/    # Code source
│   └── resources/                 # Configuration
└── test/                          # Tests unitaires
```
